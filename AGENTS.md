# ServicePilot product documentation

- Treat `docs/ServicePilot_PRD_v1.0.docx` as the current product requirements baseline.
- Whenever a system change affects roles, workflows, permissions, functional scope, metrics, dependencies, release behavior, or product risks, update the relevant PRD sections and its change log in the same change.
- Regenerate the Word document with `scripts/create_prd.py`, then visually inspect the rendered pages before considering the change complete.
- Do not present prototype metrics or interface sample values as validated production data.
