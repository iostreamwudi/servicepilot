# ServicePilot

企业智能客服与工单协同平台的产品验证项目，覆盖消费者咨询、AI 会话、人工接管、工单流转、知识治理、自动质检、策略配置、数据分析和安全审计。

## 当前版本

- 可交互的企业运营后台
- 消费者端咨询演示
- 多角色与权限设计
- Agent 调用链和人工接管流程
- 工单 SLA、知识版本、质检回流、策略发布和审计展示
- 企业级产品蓝图与交付路线图
- D1 持久化数据模型与首版迁移
- 身份感知的初始化和工单 API
- 可调用的 Agent API：知识命中、风险分级、置信度、可追溯引用和转人工
- 1,028 条可追溯知识：20 条已整理规则 + 1,008 条来自 21 个政府及监管官方来源的按条切片；Agent 仅检索审核生效内容，原始法规先进入待复核区
- 只读订单退款工具：订单号白名单校验、支付信息脱敏、失败禁止猜测与调用审计
- 阿里云百炼 GLM-5.2 非思考模式网关及无密钥/调用失败安全降级
- D1 版本化向量索引与生产影子 Hybrid 检索：后台记录候选变化、分差、理由、版本、失败和 P95；支持质量复核、类目/版本统计和只读灰度证据门禁，不改变现网答案来源
- 覆盖正常、边界、高风险、对抗与隐私场景的离线评测种子集
- CSDS 全量覆盖评测：读取 train/val/test 共 10,701 段对话、277,399 个轮次，对全部 21,126 个标注问题逐条测试；另保留 4,196 条四类去重专项集，与高成本端到端模型评测分层运行
- 真实模型回归评测：并发/冷却保护、自动规则评分、运行记录和失败明细持久化
- 组织、成员角色、会话、消息、工单、知识、质检、策略与审计关系模型

当前界面中的业务数据为产品演示数据，不代表真实生产结果。

## 自托管部署

`deploy/` 提供 Docker Compose、Nginx 反向代理、API 限流、本地持久化 D1 兼容运行时与健康检查。运行时密钥放在被 Git 忽略的 `deploy/secrets/.dev.vars`，数据库卷独立于应用容器，版本更新不会清除评测与会话状态。当前演示部署默认公开访问，生产部署应在网关层接入企业身份认证。
